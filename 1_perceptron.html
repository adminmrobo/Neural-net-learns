1문제 정의

메일이 올 때마다 몇 가지를 셉니다. 링크가 몇 개인지, 느낌표가 몇 개인지, 글자가 몇 자인지. 사람은 "링크가 잔뜩 있고 느낌표가 난무하면 스팸"처럼 감으로 판단하지만, 우리는 그 판단을 숫자로 된 규칙, 즉 함수로 만들려 합니다.

스팸 여부 = f(링크 수, 느낌표 수, 글자 수, …)

입력은 센 숫자들(특성)이고, 출력은 1(스팸) 또는 0(정상)입니다. 이것을 푸는 데 필요한 질문은 세 가지입니다. 어떻게 판단하나, 얼마나 틀렸나, 숫자 크기가 제각각인데 괜찮나. 이 시리즈의 1~4편이 세 질문에 하나씩 답하고, 5편 실험실에서 모두 직접 돌려 보고, 6편에서 모델들을 "답하는 방식"으로 다시 정리합니다.

01

퍼셉트론Perceptron

신경망의 가장 작은 부품. 곱하고, 더하고, 문턱과 비교합니다.z = Σ wᵢxᵢ + b → f(z)

1모델

입력마다 중요도(가중치)를 곱해 모두 더하고, 그 점수가 기준 이상이면 1(스팸), 아니면 0(정상)이라고 답하는 모델입니다. 1958년 로젠블랫이 뇌의 신경세포 하나를 흉내 내어 만들었고, 오늘날의 인공신경망은 모두 이 부품을 수없이 이어 붙인 것입니다.

입력숫자 여러 개 x₁ … xₙ
출력0 또는 1
학습 방법틀릴 때마다 w, b 수정

쉽게 말하면스팸 점수표입니다. "링크 수 × 0.8 + 느낌표 수 × 0.5 − 3"을 계산해 0 이상이면 스팸함으로 보냅니다. 배점 0.8과 0.5가 가중치 w이고, 기준선을 옮기는 −3이 편향 b입니다. 퍼셉트론은 이 배점을 사람이 정하지 않고, 예시 메일을 보며 스스로 고칩니다.

2수식
z = Σi=1…n wᵢxᵢ + b = w₁x₁ + w₂x₂ + … + wₙxₙ + b
ŷ = f(z) = { 1 if z ≥ 0,  0 otherwise }f는 계단 함수(step)입니다. 이 f 자리를 다른 함수로 바꾼 것이 2편에서 볼 활성화 함수입니다.
학습 규칙:  w ← w + η (y − ŷ) x,    b ← b + η (y − ŷ)
xᵢ
입력 특성. 링크 수, 느낌표 수처럼 센 숫자
wᵢ, b
가중치와 편향. 데이터로 찾아야 하는 빈칸
η (에타)
학습률. 한 번에 얼마나 크게 고칠지
y − ŷ
정답 − 예측. 맞으면 0이라 아무것도 바뀌지 않음
수식 한 조각씩 읽기
  1. Σ wᵢxᵢΣ(시그마)는 "모두 더하라"는 기호입니다. 같은 번호끼리 곱해서(w₁x₁, w₂x₂, …) 전부 더합니다. 이것을 가중합이라고 부릅니다.
  2. + b편향입니다. 문턱의 높이를 옮깁니다. b가 −3이면 가중합이 3 이상이어야 z가 0 이상이 됩니다.
  3. f(z) = step계단 함수입니다. z가 0 이상이면 1, 아니면 0. 중간값 없이 딱 잘라 판단합니다.
  4. w ← w + η(y − ŷ)x화살표 ←는 "오른쪽 값으로 바꿔 넣는다"는 뜻입니다. 맞히면 y − ŷ = 0이라 그대로입니다. 스팸(1)을 정상(0)으로 틀렸으면 x를 더해 z를 키우고, 정상을 스팸으로 틀렸으면 x를 빼서 z를 줄입니다.
숫자로 한 번 해 보기w = (0.8, 0.5), b = −3, 링크 2개·느낌표 3개인 메일 x = (2, 3): z = 0.8×2 + 0.5×3 − 3 = 0.1 ≥ 0 → ŷ = 1 (스팸)
실제로는 정상(y = 0)이었다면 (η = 0.1): w ← (0.8, 0.5) − 0.1×(2, 3) = (0.6, 0.2), b ← −3 − 0.1 = −3.1
다시 계산: z = 0.6×2 + 0.2×3 − 3.1 = −1.3 < 0 → ŷ = 0. 이제 맞힙니다.

4해석

왼쪽 입력 x₁ … xₙ에 각각 가중치 w₁ … wₙ를 곱하고, 편향 b를 더해 점수 z를 만듭니다. 이 점수를 f(계단 함수)에 넣어 0 이상이면 1, 아니면 0을 냅니다.

입력이 두 개(링크 수, 느낌표 수)라면 평면에서 z = 0인 곳, 즉 w₁x₁ + w₂x₂ + b = 0이 직선입니다. 이 직선의 한쪽은 스팸, 반대쪽은 정상이 됩니다. w는 직선의 기울어진 방향을, b는 직선의 위치를 정합니다. 이 직선을 결정 경계라고 부릅니다.

학습은 틀린 예시를 만날 때마다 직선을 그 예시 쪽으로 조금 돌리는 것이 전부입니다. 모든 예시를 맞히는 직선을 하나 찾으면 멈춥니다.

5움직이는 다이어그램 · 퍼셉트론이 배우는 과정

가로는 링크 수, 세로는 느낌표 수입니다. 틀리게 분류된 메일을 하나 골라 z를 계산하고, 학습 규칙대로 w를 고치면 직선이 돕니다. 틀린 메일(✕)이 없어질 때까지 반복합니다. 계산에는 링크 수와 느낌표 수에서 5를 빼고 5로 나눈 값(−1 ~ 1)을 넣었습니다. 4편에서 볼 정규화를 미리 쓴 것입니다. η = 0.3.

  2. z로 확인
  3. 직선 수정
  4. 모두 맞으면 끝

9퍼셉트론 하나로 안 되는 문제: XOR

"링크가 있거나 느낌표가 있으면 스팸, 둘 다 있거나 둘 다 없으면 정상"이라는 이상한 규칙을 생각해 봅시다. 네 점을 찍으면 오른쪽처럼 대각선끼리 같은 클래스가 됩니다. 이것을 XOR(배타적 논리합)이라고 합니다.

직선을 어떻게 그어도 ● 두 개와 ○ 두 개를 한쪽씩 모을 수 없습니다. 퍼셉트론의 결정 경계는 직선 하나뿐이므로, 이 문제는 풀리지 않습니다. 1969년 이 한계가 널리 알려지며 신경망 연구가 한동안 식었습니다.

해결책은 퍼셉트론을 여러 층으로 쌓고, 층 사이에 꺾이는 활성화 함수를 넣는 것입니다. 그러려면 계단 대신 어떤 함수를 써야 할지, 여러 층의 가중치를 어떻게 고칠지 알아야 합니다. 이것이 2편과 3편의 주제입니다.

가로는 링크 수, 세로는 느낌표 수, 점은 학습 메일입니다(같은 칸의 점이 겹치지 않게 살짝 흔들어 찍었습니다). 계산에는 4편에서 볼 표준화를 한 값을 넣고, η = 0.3입니다. 한 장은 메일을 한 바퀴 다 돈 뒤(에포크 하나)의 실제 상태이며, 장과 장 사이를 섞어 잇지 않습니다.

세트
정상 메일스팸 메일배경: 퍼셉트론의 판정

2해석 · 수렴과 기준선

쉬운 세트는 업무 메일(링크·느낌표가 거의 없음)과 광고 스팸(둘 다 많음)이라 직선 하나로 완전히 나뉩니다. 퍼셉트론은 몇 에포크 만에 틀린 메일이 0이 되고 멈춥니다. 1958년부터 알려진 수렴 정리가 보장하는 그대로입니다.

어려운 세트는 뉴스레터와 피싱 스팸이 링크 2~5개, 느낌표 1~3개 근처에 함께 몰려 있습니다. 직선이 한 메일을 맞히려고 돌면 다른 메일이 틀리고, 이것이 끝없이 반복됩니다. 멈춘 직선은 정답이 아니라 "정해 둔 에포크가 끝난 자리"입니다.

막대의 세로선은 기준선입니다. 아무것도 배우지 않고 "학습 데이터에서 더 많은 쪽"(여기서는 정상)으로만 답해도 쉬운 세트에서 0.714, 어려운 세트에서 0.667을 받습니다. 정확도는 이 선보다 높아야 의미가 있습니다. 정식 코드에서는 어려운 세트의 시험 정확도가 0.550으로, 기준선보다 낮았습니다.

모델의 부품
퍼셉트론
비유서류 전형 점수표. 항목별 점수에 배점을 곱해 더하고, 합격선을 넘으면 통과입니다.
뜻입력에 가중치를 곱해 더하고 편향을 더한 값을 활성화 함수에 넣어 답을 내는 가장 작은 신경망 부품.
특성
비유건강검진표의 항목. 키, 몸무게, 혈압처럼 대상을 숫자로 적은 칸 하나하나입니다.
뜻모델에 넣는 입력 숫자 하나. 이 페이지에서는 글자 수, 링크 수, 느낌표 수.
가중치
비유요리 레시피의 재료 비율. 소금을 두 배 넣으면 맛이 크게 바뀌듯, 가중치가 큰 입력이 판단을 크게 좌우합니다.
뜻입력 하나하나가 결과에 얼마나 영향을 주는지 나타내는 숫자 w. 학습이 찾아내는 대상입니다.
편향
비유체중계의 영점 나사. 아무것도 올리지 않았을 때 바늘이 가리키는 위치를 옮겨 줍니다.
뜻식 w·x + b의 b. 결정 경계를 평행 이동시킵니다.
가중합
비유장보기 계산. 품목별로 수량 × 가격을 곱해 모두 더하면 총액이 나옵니다.
뜻w₁x₁ + w₂x₂ + … + wₙxₙ. 같은 번호끼리 곱해서 모두 더한 값(내적).
결정 경계
비유지도 위의 국경선. 선 이쪽이면 A국, 저쪽이면 B국입니다.
뜻모델의 답이 바뀌는 지점을 이은 선(또는 면). 퍼셉트론에서는 w·x + b = 0인 직선.
XOR
비유"둘 중 하나만" 규칙. 커피와 차 가운데 딱 하나만 마시면 통과, 둘 다거나 둘 다 아니면 탈락입니다.
뜻두 입력이 서로 다를 때만 1인 논리 연산. 직선 하나로 나눌 수 없어 퍼셉트론 하나로는 풀지 못합니다.
성적 읽기
수렴
비유흔들리던 저울 바늘이 한 자리에 멈추는 것.
뜻학습을 반복해도 가중치가 더 바뀌지 않고 한 자리에 머무는 상태. 퍼셉트론은 직선으로 나뉘는 데이터에서만 수렴이 보장됩니다.
학습·시험 데이터
비유연습 문제집과 실제 시험지. 연습 문제만 잘 풀어서는 실력을 알 수 없습니다.
뜻모델이 배우는 데 쓰는 데이터(학습)와, 다 배운 뒤 처음 보는 데이터로 성적을 매기는 데 쓰는 데이터(시험).
기준선
비유찍기 점수. 문제를 읽지 않고 가장 흔한 답 하나만 골랐을 때 받는 점수입니다.
뜻학습 데이터에서 더 많은 쪽 하나로만 답했을 때의 시험 정확도. 모델 점수는 이것보다 높아야 의미가 있습니다.
