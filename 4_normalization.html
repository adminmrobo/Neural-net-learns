정규화 — 숫자의 눈금을 맞춘다

글자 수는 수천, 링크 수는 0~12. 크기가 다른 숫자를 같은 눈금으로 맞추는 정규화를 봅니다. 메일 데이터에서 글자 수를 더하는 순간 어려운 세트가 풀리지만, 표준화 없이는 그 정보를 쓰지 못하는 장면을 확인합니다. 이름이 비슷한 규제도 직접 걸어 봅니다.

하루

글자 수는 수천인데 링크 수는 0에서 12예요. 이걸 그냥 같이 넣어도 돼요?

박사

두 자의 눈금부터 맞춰야지요. 그게 정규화입니다.

글 · 안상선 ((주)M-Robo 대표) · 저자 소개

● 정상 메일 (y = 0) · ○ 스팸 메일 (y = 1) · ◆ 지금 보고 있는 메일

01

정규화Normalization

숫자들의 기준점(평균)과 눈금(퍼짐)을 맞춥니다. 입력에 미리 한 번 하는 방법과, 신경망 층 안에서 매번 하는 방법이 있습니다.x̂ = (x − μ) / σ

1왜 필요한가

메일의 글자 수는 400~4,400, 링크 수는 0~7입니다. 이대로 넣으면 글자 수의 가중치를 0.001만 바꿔도 점수 z가 크게 흔들리고, 링크 수의 가중치는 한참 바꿔야 겨우 움직입니다. 그러면 한 가지 학습률로 두 가중치를 함께 고치기 어렵습니다. 정규화는 모든 특성을 평균 0, 표준편차 1 근처로 옮겨 같은 눈금에서 비교하게 합니다.

입력크기가 제각각인 숫자
출력평균 0, 퍼짐 1 근처
효과빠르고 안정적인 학습

쉽게 말하면표준점수입니다. 수학은 100점 만점에 평균 60점, 영어는 10점 만점에 평균 6점이라면 원점수 80점과 8점을 직접 비교할 수 없습니다. "평균보다 표준편차 몇 개만큼 위인가"로 바꾸면 두 과목을 같은 눈금에서 볼 수 있습니다.

2수식 · 입력 정규화
표준화:   x̂ = (x − μ) / σ,    μ = (1/n) Σ xᵢ,   σ = √[(1/n) Σ (xᵢ − μ)²]
최소-최대 정규화:   x̂ = (x − min) / (max − min)   → 0 ~ 1

σ (시그마)
표준편차. 퍼짐을 1로 맞출 때 나누는 값
σ²
분산. 표준편차의 제곱

평균 μ / 표준편차 σ2,000 / 1,496.70 / 13 / 2.550 / 1
숫자로 한 번 해 보기글자 수: μ = (1,200 + 400 + 4,400 + 2,000) / 4 = 2,000,  σ = √[(800² + 1,600² + 2,400² + 0²) / 4] = 1,496.7
메일 ③: (4,400 − 2,000) / 1,496.7 = 1.60  → "평균보다 표준편차 1.6개만큼 길다"
링크 수: μ = 3, σ = 2.55  → 메일 ②: (7 − 3) / 2.55 = 1.57. 이제 두 특성이 모두 −1.2 ~ +1.6 사이의 같은 눈금입니다.

실전에서 지킬 점: μ와 σ는 학습 데이터로만 계산하고, 시험 데이터와 새 메일에는 그 값을 그대로 씁니다. 시험 데이터까지 섞어서 계산하면 답을 미리 엿본 셈이 됩니다.

3움직이는 다이어그램 · 정규화 전과 후, 같은 경사하강법

등고선은 비용 J의 높이를 나타내고, 가운데가 바닥입니다. 글자 수처럼 큰 숫자에 곱해지는 가중치 w₁은 조금만 움직여도 J가 크게 변해서, 정규화 전의 골짜기는 한쪽으로 가파르고 길쭉합니다. 같은 출발점, 같은 학습률(η = 0.09)로 내려가 봅니다. 등고선 모양은 원리를 보여 주기 위한 예시입니다. 실제로는 특성끼리 상관이 있으면(글자가 길수록 링크도 많은 식) 표준화 뒤에도 기울어진 타원이 남을 수 있습니다. 표준화는 골짜기를 "덜 길쭉하게" 만드는 것이지, 늘 완벽한 원으로 만드는 것은 아닙니다.

  1. 같은 출발점, 같은 학습률
  2. 한 걸음씩 내려가기
  3. 도착한 걸음 수 비교
4층 안의 정규화 · 어떤 값끼리 평균을 내나

입력만 정규화해도, 층을 지나면 값의 크기가 다시 제각각이 됩니다. 그래서 신경망은 층 사이에서도 정규화합니다. 방법은 여러 가지지만 공식은 같고, 평균과 분산을 계산할 값의 묶음만 다릅니다. 방법을 고르고 입력 표의 칸을 눌러 보세요. 테두리가 쳐진 칸들이 그 칸의 기준 묶음입니다.

방법 그룹 수 G
입력 (배치 3개 × 채널 6개)
출력 (같은 모양)

표의 칸 하나는 실제로는 값 여러 개(이미지라면 H × W 크기의 지도)일 수 있지만, 여기서는 원리를 보이려고 숫자 하나로 줄였습니다. γ = 1, β = 0, ε = 0.00001로 계산했습니다.

5수식 · 층 정규화 네 가지
x̂ = (x − μ) / √(σ² + ε),    y = γ x̂ + βBatchNorm, LayerNorm, GroupNorm이 모두 이 공식을 씁니다. ε은 0으로 나누지 않게 더하는 아주 작은 수, γ와 β는 학습으로 정하는 "다시 늘리고 옮기는" 값입니다.
RMSNorm:   y = γ · x / √(mean(x²) + ε)평균을 빼지 않고, 제곱평균제곱근(RMS)으로만 나눕니다. 계산이 한 단계 줄어듭니다.
방법평균·분산을 내는 묶음배치에 의존?학습하는 값주로 쓰는 곳
BatchNorm같은 채널, 배치 안의 모든 예시와 모든 공간 위치(H × W)예. 추론 때는 학습 중 모아 둔 이동 평균을 씀γ, β이미지 CNN (배치가 넉넉할 때)
LayerNorm한 예시(토큰) 안의 모든 특성아니오. 학습과 추론 규칙이 같음γ, β트랜스포머, 순환 신경망
GroupNorm한 예시 안, 채널 묶음(그룹) 하나아니오. 그룹 수 G는 설계자가 정함γ, β배치가 작은 CNN (물체 검출·분할)
RMSNorm한 토큰 안의 모든 특성, 평균은 빼지 않음아니오γ최근 대형 언어 모델 (LLaMA 계열 등)
6해석

BatchNorm은 "이 채널 값이 이번 배치의 다른 예시들과 비교해 큰가 작은가"를 봅니다. 배치가 충분히 크면 효과가 좋지만, 배치가 작거나(위 실습의 "배치를 1개로") 문장 길이가 제각각이면 통계가 불안정해집니다.

LayerNorm은 다른 예시를 보지 않고 한 토큰 안의 특성끼리만 비교합니다. 배치 크기와 상관없이 늘 같은 규칙이라 트랜스포머의 표준이 되었습니다. RMSNorm은 여기서 평균 빼기를 생략해 더 가볍게 만든 것이고, GroupNorm은 채널을 몇 묶음으로 나눠 LayerNorm과 채널별 정규화의 중간을 택한 것입니다.

외우는 요령: 표를 그리고, 평균을 함께 낼 칸에 동그라미를 쳐 보면 동작이 예측됩니다. 동그라미가 여러 예시에 걸치면 배치에 의존하고, 한 예시 안에 머물면 배치와 무관합니다.

!같은 "정규화", 다른 뜻 하나

우리말로는 둘 다 "정규화"라고 부르는 경우가 있어 헷갈립니다. 이 페이지의 정규화는 normalization(값의 크기 맞추기)입니다. 영어로 regularization은 보통 규제라고 번역하며, 3편의 비용 함수에 벌점을 하나 더 붙이는 기법입니다.

J규제 = J + λ Σ wᵢ²L2 규제: 가중치가 너무 커지면 벌점을 줘서, 학습 데이터를 외워 버리는 과대적합을 줄입니다. λ가 벌점의 세기입니다.

2해석 · 정보와 눈금은 따로 필요하다

링크·느낌표만으로는 어려운 세트가 기준선 근처였습니다(2편). 뉴스레터는 평균 4,150자, 피싱 스팸은 1,540자라 글자 수를 더하면 두 무리가 갈라집니다. 정식 코드에서 시험 정확도는 0.683 → 0.983으로 뜁니다.

그런데 이 정보는 표준화를 해야만 쓸 수 있습니다. 글자 수는 수천, 링크 수는 0~12라, 같은 학습률이 한쪽에는 너무 크고 다른 쪽에는 너무 작습니다. η = 1이면 글자 수 가중치가 한 걸음에 수천씩 튀어 시그모이드가 0이나 1에 붙고, η를 아주 작게 하면 링크·느낌표 가중치가 거의 움직이지 않습니다. 표준화하면 세 특성이 같은 눈금이 되어, 한 학습률로 모두 알맞게 움직입니다.

규제 · 가중치에 벌점 매기기Regularization (L2)

이름이 비슷한 다른 기법, 규제(regularization)를 직접 걸어 봅니다. 벌점의 세기 λ를 바꾸면 가중치와 정확도가 어떻게 변할까요?

초파리 연구원

벌점을 너무 세게 매기면 다 같이 굶어. 적당히가 중요해!

1λ를 키우면 가중치가 줄어든다

어려운 세트, 표준화한 세 특성, 로지스틱 회귀(η = 0.5, 300걸음)입니다. 비용에 λ/2 · Σw²를 더하면, 기울기에는 λw가 더해져 매 걸음 가중치를 0 쪽으로 조금씩 당깁니다.

J규제 = J + (λ/2) Σ wᵢ²,    w ← w − η (∂J/∂w + λw)

λ = 0 · 0.01 · 0.1 · 0.5 · 2

가중치 (표준화한 눈금)
정확도

2해석 · 규제는 과대적합을 막는 브레이크

규제는 "꼭 필요한 만큼만 큰 가중치"를 고르게 합니다. 특성이 수천 개이고 데이터가 적을 때, 모델은 학습 메일의 우연한 특징까지 외워 버리기 쉽습니다(과대적합). 가중치에 벌점을 매기면 그런 외우기가 비싸져서 새 메일에도 통하는 규칙이 남습니다.

우리 메일 데이터는 특성이 세 개뿐이라 과대적합이 거의 없고, 그래서 약한 규제는 점수를 바꾸지 않습니다. 반대로 λ를 너무 키우면 쓸모 있는 가중치까지 눌려 기준선으로 떨어집니다. 정식 코드에서도 C = 1/λ가 100, 1일 때 시험 0.983, 0.01일 때 0.733이었습니다.

이 편에서 점선 밑줄이 있는 단어를 누르면 같은 비유가 뜹니다. 여기서는 한꺼번에 훑어볼 수 있습니다.
입력 정규화
정규화
비유표준점수. 만점이 다른 과목들을 "평균보다 얼마나 위인가"로 바꿔 같은 눈금에서 비교합니다.
뜻값에서 평균을 빼고 퍼짐으로 나눠 크기를 맞추는 일(normalization).
표준화
비유반 평균을 0점, 보통의 차이를 1점으로 새 눈금을 긋는 것.
뜻(x − μ) / σ. 평균 0, 표준편차 1로 바꾸는 가장 흔한 입력 정규화.
표준편차
비유반 학생들 키가 평균에서 보통 몇 cm쯤 떨어져 있는지.
뜻값들이 평균에서 퍼진 정도 σ. 분산 σ²의 제곱근.
데이터 누수
비유시험 문제를 미리 엿본 것. 점수는 높지만 실력은 아닙니다.
뜻시험 데이터의 정보(예: 평균·표준편차)가 학습 과정에 섞여 들어가 성적이 실제보다 좋게 나오는 실수.
층 정규화
배치
비유한 번에 채점하는 답안지 묶음.
뜻한 번의 가중치 수정에 함께 쓰는 예시들의 묶음. 그 개수가 배치 크기.
BatchNorm
비유같은 과목 점수를 반 전체와 비교하기. 반 인원이 적으면 비교가 흔들립니다.
뜻같은 채널 값을 배치 안의 모든 예시에 걸쳐 평균·분산으로 정규화. 배치 크기에 의존합니다.
LayerNorm
비유한 학생의 여러 과목 점수를 그 학생 자신의 평균과 비교하기.
뜻한 예시(토큰) 안의 모든 특성으로 평균·분산을 내 정규화. 배치와 무관하며 트랜스포머의 표준.
GroupNorm
비유한 학생의 과목을 문과·이과 묶음으로 나눠, 묶음 안에서만 비교하기.
뜻한 예시 안에서 채널을 G개 그룹으로 나눠 그룹마다 정규화. 작은 배치의 CNN에서 씁니다.
RMSNorm
비유평균은 따지지 않고 "전체적으로 얼마나 큰 목소리인가"만 맞추는 볼륨 조절.
뜻평균을 빼지 않고 √mean(x²)으로만 나누는 정규화. LayerNorm보다 계산이 적습니다.
규제
규제
비유과식 벌금. 가중치가 너무 커지면 벌점을 매겨 모델이 문제집 답을 외우지 못하게 합니다.
뜻비용 함수에 가중치 크기 벌점(예: λΣw²)을 더해 과대적합을 줄이는 기법(regularization).
과대적합
비유기출문제 답만 외운 학생. 기출은 만점이지만 새 문제는 못 풉니다.
뜻학습 데이터에는 잘 맞지만 새 데이터에서는 성능이 떨어지는 상태.

4편의 핵심 세 줄
  1. 표준화는 학습 데이터의 μ, σ로 (x − μ)/σ를 계산해 모든 특성을 같은 눈금에 둡니다.
  2. 정보(글자 수)와 눈금(표준화)은 따로 필요합니다. 하나만으로는 어려운 세트가 풀리지 않았습니다.
  3. 층 정규화는 '어떤 값끼리 평균을 내나'만 다르고, 규제는 가중치에 벌점을 매기는 다른 기법입니다.
